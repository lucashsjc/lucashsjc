## 📌 Featured project

### 🎂 [Ateliê Doce Festa](https://github.com/lucashsjc/app-doceria): bakery management system

An installable web app (PWA) that replaced the paper notebook a bakery in São José dos Campos used to track its business. It is in daily use.

- Orders, customers, production schedule, payments and overdue tracking, menu, PDF contracts, and revenue and profit-per-product reports
- Requirements gathered with the client, with each stage validated by her before release
- PostgreSQL (Supabase) with per-user access control (Row Level Security)
- Continuous deployment via GitHub and Vercel, built with AI-assisted development

`TypeScript` · `React` · `PostgreSQL` · `Supabase` · `Vercel` · `PWA`
