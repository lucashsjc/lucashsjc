## 📌 Projeto em destaque

### 🎂 [Ateliê Doce Festa](https://github.com/lucashsjc/app-doceria): sistema de gestão para confeitaria

App web que pode ser instalado no celular (PWA) e substituiu o controle em caderno de uma confeitaria de São José dos Campos. Está em uso diário.

- Pedidos, clientes, agenda de produção, pagamentos e inadimplência, cardápio, contratos em PDF e relatórios de faturamento e lucro por produto
- Requisitos levantados com a cliente e entregas em etapas validadas com ela antes de cada publicação
- PostgreSQL (Supabase) com controle de acesso por usuário (Row Level Security)
- Deploy contínuo via GitHub e Vercel, com desenvolvimento assistido por IA
